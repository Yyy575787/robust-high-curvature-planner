## 3. 本周失败案例与判断

### 3.1 Windows 安装失败

在 Windows 的 Python 3.8 Conda 环境中执行 `pip install commonroad-reactive-planner` 时，`polygon3` 和 `commonroad-drivability-checker` 构建失败，主要原因是缺少 MSVC 14+ 编译工具链。

**处理决定：** 不再把 Windows 作为当前研究的主要复现环境，统一转到 Ubuntu 22.04，以降低依赖编译和跨平台差异带来的成本。

### 3.2 Ubuntu 环境仍未完全闭环

Ubuntu 22.04 + Python 3.10 下，Reactive Planner 及主要依赖已经安装成功，但 `pip check` 仍提示缺少 `jinja2` 和 `typeguard`。

这些问题未必直接阻塞规划器运行，但在冻结基线环境前必须修复，或者在环境说明中解释其来源和影响。

### 3.3 基线复现未完成

本周最大的阻塞并不是“软件没有安装成功”，而是尚未完成以下闭环：

> 固定源码版本 → 运行官方示例 → 保存运行命令与配置 → 保存日志和轨迹结果 → 提交可复现材料

因此，目前还不能进入算法修改和对比实验阶段。
